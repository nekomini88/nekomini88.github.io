电子书网站合集

2026-05-20 #电子书

📚 电子书 / 学术资源网站合集

整理时间：2026
类型：电子书｜论文｜教材｜漫画｜Kindle｜古籍｜搜书引擎
适合：Kindle 用户、程序员、学生、科研党、小说爱好者

🔥 常用核心资源站（推荐收藏）

网站 类型 特点
Z-Library 综合电子书 小说 / 畅销书 / Kindle 资源丰富
WeLib 综合搜索 类似 Anna’s Archive，中文友好
Anna’s Archive 元搜索引擎 聚合 Z-Library / LibGen / Sci-Hub
苦瓜书盘 中文电子书 epub / mobi 质量高
搬书匠 IT 技术书 Java / Python / AI / 算法
Mobi 图书网 Kindle 资源站 小说 / 网文 / mobi 格式

🌐 综合影子图书馆 / 元搜索引擎

类似：Anna’s Archive + Z-Library
适合：找冷门书、绝版书、英文教材、学术论文

📖 Anna’s Archive

🔗 https://annas-archive.gl

特点

  • 当前最大影子图书馆之一

  • 聚合：

    • Z-Library
    • LibGen
    • Sci-Hub

  • 中英文资源极其丰富

  • 支持：

    • epub
    • mobi
    • pdf

  • 搜索能力非常强

推荐指数

⭐⭐⭐⭐⭐

📚 Z-Library

🔗 https://zh.z-library.sk

特点

  • 中文小说非常多
  • Kindle 用户常用
  • 畅销书更新快
  • 下载速度通常较快

注意事项

⚠️ 假站很多，建议关注最新地址镜像。

推荐指数

⭐⭐⭐⭐⭐

📘 WeLib

🔗 https://zh.welib.org

特点

  • 类似 Anna 的镜像聚合
  • 中文界面体验不错
  • 学术资源较多

推荐指数

⭐⭐⭐⭐

📗 Library Genesis（LibGen）

🔗 常用镜像：

  • https://libgen.li
  • https://libgen.la
  • https://libgen.gs

特点

  • 老牌资源站
  • 大学教材极多
  • CS / 数学 / AI 非常强
  • PDF 资源丰富

推荐指数

⭐⭐⭐⭐⭐

🇨🇳 中文电子书 / 搜书引擎

🔍 鸠摩搜书

🔗 https://www.jiumodiary.com

特点

  • 中文搜书神器

  • 聚合多个资源站

  • 支持：

    • epub
    • mobi
    • pdf

  • 百度网盘资源很多

推荐指数

⭐⭐⭐⭐⭐

  • 检索速度快

  • 配合 Calibre 管理电子书
