    📚 电子书 / 学术资源网站合集

    整理时间：2026
    类型：电子书｜论文｜教材｜漫画｜Kindle｜古籍｜搜书引擎
    适合：Kindle 用户、程序员、学生、科研党、小说爱好者

    🔥 常用核心资源站（推荐收藏）

    网站 类型 特点
    Z-Library 综合电子书 小说 / 畅销书 / Kindle 资源丰富
    WeLib 综合搜索 类似 Anna’s Archive，中文友好
    Anna’s Archive 元搜索引擎 聚合 Z-Library / LibGen / Sci-Hub
    苦瓜书盘 中文电子书 epub / mobi 质量高
    搬书匠 IT 技术书 Java / Python / AI / 算法
    Mobi 图书网 Kindle 资源站 小说 / 网文 / mobi 格式

    🌐 综合影子图书馆 / 元搜索引擎

    类似：Anna’s Archive + Z-Library
    适合：找冷门书、绝版书、英文教材、学术论文

    📖 Anna’s Archive

    🔗 https://annas-archive.gl

    特点

    • 当前最大影子图书馆之一

    • 聚合：

      • Z-Library
      • LibGen
      • Sci-Hub

    • 中英文资源极其丰富

    • 支持：

      • epub
      • mobi
      • pdf

    • 搜索能力非常强

    推荐指数

    ⭐⭐⭐⭐⭐

    📚 Z-Library

    🔗 https://zh.z-library.sk

    特点

    • 中文小说非常多
    • Kindle 用户常用
    • 畅销书更新快
    • 下载速度通常较快

    注意事项

    ⚠️ 假站很多，建议关注最新地址镜像。

    推荐指数

    ⭐⭐⭐⭐⭐

    📘 WeLib

    🔗 https://zh.welib.org

    特点

    • 类似 Anna 的镜像聚合
    • 中文界面体验不错
    • 学术资源较多

    推荐指数

    ⭐⭐⭐⭐

    📗 Library Genesis（LibGen）

    🔗 常用镜像：

    • https://libgen.li
    • https://libgen.la
    • https://libgen.gs

    特点

    • 老牌资源站
    • 大学教材极多
    • CS / 数学 / AI 非常强
    • PDF 资源丰富

    推荐指数

    ⭐⭐⭐⭐⭐

    🇨🇳 中文电子书 / 搜书引擎

    适合：中文小说、社科、网文、Kindle 阅读

    🔍 鸠摩搜书

    🔗 https://www.jiumodiary.com

    特点

    • 中文搜书神器

    • 聚合多个资源站

    • 支持：

      • epub
      • mobi
      • pdf

    • 百度网盘资源很多

    推荐指数

    ⭐⭐⭐⭐⭐

    🔎 24H 搜书

    🔗 https://24hbook.com

    特点

    • 支持 ISBN 搜索
    • 中文资源质量不错
    • 检索速度快

    推荐指数

    ⭐⭐⭐⭐

    🐼 熊猫搜书

    🔗 https://xmsoushu.com

    特点

    • 聚合多个搜书工具
    • 一站式搜索
    • 分类较清晰

    推荐指数

    ⭐⭐⭐⭐

    🐰 小兔搜书

    🔗 常见镜像：ss.yesky.online

    特点

    • 搜索过滤能力强
    • 查找特定格式方便

    推荐指数

    ⭐⭐⭐

    📚 SoBooks

    🔗 https://sobooks.net

    特点

    • 社科 / 文学资源优秀
    • 排版较好
    • 更新频繁

    推荐指数

    ⭐⭐⭐⭐

    💻 程序员 / 技术书资源站

    🧠 搬书匠

    🔗 https://banshujiang.cn

    特点

    • 程序员经典资源站
    • 技术书非常全

    重点方向

    • Java
    • Python
    • Go
    • Rust
    • AI
    • 算法
    • 计算机网络

    推荐指数

    ⭐⭐⭐⭐⭐

    📙 苦瓜书盘

    🔗 https://kgbook.com

    特点

    • Kindle 格式优秀
    • mobi / epub 丰富
    • 中文书质量高

    推荐指数

    ⭐⭐⭐⭐

    📕 Mobi 图书网

    🔗 https://mobitushu.com

    特点

    • mobi 资源丰富
    • 网文 / 小说很多
    • 适合 Kindle

    推荐指数

    ⭐⭐⭐⭐

    🎓 学术 / 论文资源站

    🔬 Sci-Hub

    🔗 https://sci-hub.se

    功能

    • DOI 下载
    • 学术论文获取
    • 期刊资源

    适合

    • 科研
    • 毕设
    • 论文阅读

    推荐指数

    ⭐⭐⭐⭐⭐

    🏛 Internet Archive

    🔗 https://archive.org

    特点

    • 合法公开资源
    • 老书 / 杂志 / 历史文献
    • 可在线借阅

    推荐指数

    ⭐⭐⭐⭐⭐

    📖 Open Library

    🔗 https://openlibrary.org

    特点

    • 类似线上图书馆
    • 可借阅电子书
    • 英文资源丰富

    推荐指数

    ⭐⭐⭐⭐

    🏺 古籍 / 文学资源站

    📜 书格

    🔗 https://www.shuge.org

    特点

    • 古籍善本
    • 高清扫描
    • 收藏价值高

    推荐指数

    ⭐⭐⭐⭐⭐

    📘 好读

    🔗 https://www.haodoo.net

    特点

    • 繁体中文经典文学
    • 适合 Kindle

    推荐指数

    ⭐⭐⭐⭐

    🎌 漫画 / 轻小说资源站

    🌸 Nyaa

    🔗 https://nyaa.si

    特点

    • 动漫资源
    • 轻小说
    • 漫画合集

    推荐指数

    ⭐⭐⭐⭐

    📚 MangaDex

    🔗 https://mangadex.org

    特点

    • 在线漫画
    • 多语言支持
    • 社区维护

    推荐指数

    ⭐⭐⭐⭐

    🛠 Kindle / 阅读工具推荐

    📱 Calibre

    🔗 https://calibre-ebook.com

    功能

    • epub ↔ mobi ↔ azw3 转换
    • Kindle 管理
    • 元数据整理
    • 自动推送

    推荐指数

    ⭐⭐⭐⭐⭐

    🤖 Telegram 找书机器人

    很多资源站都有 TG Bot：

    • Z-Library Bot
    • Anna Archive Bot
    • 中文搜书机器人

    优点

    • 搜索速度快
    • 移动端方便
    • 下载链接集中

    🎯 按用途推荐组合

    📖 中文小说

    推荐：

    • Z-Library
    • WeLib
    • 鸠摩搜书
    • Mobi 图书网

    💻 学习编程 / 算法 / AI

    推荐：

    • Anna’s Archive
    • LibGen
    • 搬书匠

    🏺 找绝版书 / 古籍

    推荐：

    • Anna’s Archive
    • Internet Archive
    • 书格

    ⚠️ 注意事项

    域名经常变化

    这类网站：

    • 经常更换镜像
    • 有很多假站
    • 建议收藏备用网址

    推荐做法

    建议：

    • 使用书签管理
    • 配合 Calibre 管理电子书
    • Kindle 用户优先下载 epub

    📌 收藏建议

    建议至少收藏：

    基本已经覆盖：

    • 小说
    • 技术书
    • 教材
    • 论文
    • Kindle
    • 古籍
    • 漫画

    等绝大多数需求。

    • 电子书
