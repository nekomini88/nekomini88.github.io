FFmpeg 常用命令汇总（2026最新整理）

FFmpeg 是功能最强大的音视频处理工具，命令基本格式：

1. 基础信息查询

命令 作用
ffmpeg -version 查看版本
ffmpeg -h 帮助信息
ffmpeg -formats 支持的封装格式
ffmpeg -codecs 支持的编解码器
ffmpeg -encoders 支持的编码器
ffmpeg -decoders 支持的解码器
ffmpeg -filters 支持的过滤器
ffmpeg -devices 支持的设备（Windows下常用）
ffmpeg -i input.mp4 查看文件详细信息（推荐加 -hide_banner）

2. 视频格式转换

常用参数：

  • -c:v libx264 / -vcodec libx264：视频编码器
  • -c:a aac / -acodec aac：音频编码器
  • -c copy：不重新编码，直接复制流（最快）

10. 常用过滤器组合（-vf）

  • fps=30：修改帧率
  • pad=width=1920:height=1080:x=0:y=0:color=black：填充黑边
  • hflip / vflip：水平/垂直翻转
  • eq=brightness=0.1:contrast=1.2：调整亮度对比度

提示

  1. 速度 vs 质量：-c copy 最快，-crf 18~24 质量好。
  2. H.265 节省空间：-vcodec hevc -crf 28
  3. 批量处理：配合 for 循环使用。
  4. 查看进度：-progress pipe:1 或 -stats
