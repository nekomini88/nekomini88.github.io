hermes命令汇总

2026-08-04 #hermes

Hermes 命令全解 — 费曼学习法版

用最直白的比喻，把 Hermes 的每一类命令讲清楚。
读完你不需要背命令，只需要记住：「我在和一家 AI 公司对话，不同的入口做不同的事。」

先打一个总比喻

Hermes 像一家万能智能助理公司。
你是老板，Hermes 是你的 AI 员工。
命令，就是你和这家公司之间的所有沟通方式。

沟通方式 类比
终端 hermes xxx 你走进公司前台，签个字填个表
聊天里 /help 你在工位上按铃问秘书”我能干啥”
Telegram 上的命令 你在微信/钉钉里给助理发消息

一、终端命令（hermes CLI）

站在公司大门口，手里拿着万能遥控器。

1. 启动 & 对话

命令 人话翻译
hermes 打开 Hermes 聊天窗口，开始唠
hermes chat -q "XX" 一次性提问，答完就走
hermes chat -q --yolo 跳过所有安全确认，直接干
hermes --resume 会话ID 捡起上次聊到一半的对话继续
hermes --continue 直接续接最近一次对话

2. 配置 & 设置

命令 人话翻译
hermes setup 向导式初始化（选模型、配终端、接网关）
hermes model 换 AI 模型（比如从 Claude 切到 DeepSeek）
hermes config 看看当前所有配置
hermes config edit 打开配置文件手动改
hermes config set 键 值 精确改某一项配置
hermes auth 管理所有 API Key / OAuth 登录
hermes doctor 体检：检查配置、依赖有没有问题
hermes status 看看 Hermes 各组件都在线吗

3. 工具 & 技能管理

命令 人话翻译
hermes tools 可视化开关各种工具（搜索、终端、文件等）
hermes tools list 列出所有工具和状态
hermes tools enable/disable NAME 启用/禁用某个工具集
hermes skills list 列出已安装的技能包
hermes skills search QUERY 去技能商店搜新技能
hermes skills install ID 安装一个技能
hermes skills inspect ID 预览技能内容，不安装
hermes skills update 更新所有过时的技能
hermes skills publish 路径 把自己写的技能发布到商店
hermes skills browse 浏览技能商店全部技能
hermes skills tap add REPO 把 GitHub 仓库加为技能源
hermes curator 自动整理技能（归档、清理、备份）

4. 定时任务（Cron）

命令 人话翻译
hermes cron list 列出所有定时任务（--all 看已禁用的）
hermes cron create "0 9 * * *" 每天早上 9 点自动执行
hermes cron edit ID 编辑任务的调度、提示词、投递目标
hermes cron pause/resume ID 暂停/恢复某个定时任务
hermes cron run ID 手动触发一次定时任务
hermes cron remove ID 删除定时任务
hermes cron status 查看调度器状态

5. 网关（多平台连接）

命令 人话翻译
hermes gateway run 前台启动网关（接 Telegram/Discord 等）
hermes gateway install 把网关装成后台服务
hermes gateway start/stop/restart 控制网关运行状态
hermes gateway setup 配置你要接的平台
hermes gateway status 网关是否在跑

6. 会话管理

命令 人话翻译

hermes sessions browse 交互式选择历史对话

hermes sessions rename ID 新名 给某次对话改名
hermes sessions delete ID 删除某次对话
hermes sessions prune 清理过期对话
hermes sessions stats 对话存储统计

7. MCP 服务器

命令 人话翻译
hermes mcp add NAME 接入一个 MCP 工具服务器
hermes mcp list 列出已接入的 MCP
hermes mcp remove NAME 断开某个 MCP
hermes mcp test NAME 测试 MCP 连接

hermes mcp install 名称 从目录安装 MCP 服务器
hermes mcp configure NAME 切换 MCP 暴露的工具

命令 人话翻译
hermes profile list 列出所有 Hermes 实例

三、Hermes 在 Telegram 上的最新命令

Telegram 上的命令分三个层级：内联斜杠命令、TG 专属功能命令、自动投递机制。

1. 内联斜杠命令（聊天框 typed）

2. Telegram 专属命令

命令 最新作用
/sethome 把当前 Telegram 聊天设为”家”频道——之后所有 cron 任务、自动推送默认发往这里
/topic 管理 Telegram 话题会话——每个话题变成独立 session，互不干扰
/platforms 或 /gateway 实时查看 Hermes 连接了哪些平台——TG、Discord、Slack、QQ、微信等在线状态一览
/approve 审批危险命令——Hermes 遇到 rm、git reset 等操作时会在 TG 弹确认，你点 approve
/deny 拒绝执行——同上，点 deny 取消
/commands 在 TG 里浏览完整命令列表——带分页
/restart 远程重启 Hermes 网关——不用 SSH 进服务器，手机直接操作
/update 远程触发 Hermes 更新——TG 里直接升级
/setcommands 配置 Bot 命令菜单——设置后 TG 输入框旁会出现命令按钮

3. Telegram Bot Menu（按钮菜单）

Hermes 在 Telegram 上还会暴露一个命令按钮菜单（通过 BotFather 的 /setcommands 设置）：

  • 用户点击输入框左侧 / 按钮或 Bot 菜单
  • 弹出常用命令列表
  • 点一下就发送，无需手动 typed

4. 自动投递机制（Cron → TG）

这不是手动 typed 的命令，但和 TG 关系最紧密：

  • 创建时指定 deliver: "telegram:频道ID"
  • 支持多平台同时投递：deliver: "telegram:-100xxx,qqbot:xxx"
  • 支持投递回原聊天：deliver: "origin"

四、核心概念串讲

用费曼的方式，把几个关键概念串起来：

什么是 Session？

Session = 一次对话的完整记录。
就像你和助理坐在会议室里聊，从进门到出门的整段对话，就是一个 Session。
/new 是”出去再进来，换一间会议室”；
/resume 是”回到刚才那间会议室继续聊”。

什么是 Cron？

Cron = 定时闹钟 + 自动执行器。
你告诉 Hermes：”每天早上 9 点帮我查天气，发给我。”
Hermes 设个闹钟，到点自动执行，结果 push 到你的 TG。
你不必在场，事情照样干。

什么是 Gateway？

Gateway = 翻译官 + 前台接待。
Telegram、Discord、Slack 发的消息，Gateway 接收后翻译成 Hermes 能懂的语言；
Hermes 的回复，Gateway 再翻译成对方平台能显示的消息。
它让你在不同平台上都能用上同一个 Hermes。

什么是 Skill？

Skill = Hermes 的工作手册。
你说”帮我生成美股日报”，Hermes 如果没装过这个技能，就得现想怎么做；
装了 us-stock-daily-report 技能后，它打开手册，按步骤执行，又快又稳。
技能越多，Hermes 越专业。

什么是 Profile？

Profile = 独立的 Hermes 员工档案。
默认 Profile 处理你的日常任务；
你可以创建 server-a Profile 管理服务器 A，server-b Profile 管理服务器 B。
每个 Profile 有独立的配置、记忆、技能，互不干扰。

六、费曼总结

Hermes 的全部命令，本质上就是「远程控制一个 AI 员工」的所有方式。
终端 CLI 是签合同的正式入口，用来安装、配置、排障。
Slash 命令 是工位上的快捷按钮，聊天内快速控制。
Telegram 网关 是把这家公司搬到了你手机上，随时发号施令，还能让 AI 自动给你发工作报告。

三条路，一个目的：让 AI 按你的意愿干活。
