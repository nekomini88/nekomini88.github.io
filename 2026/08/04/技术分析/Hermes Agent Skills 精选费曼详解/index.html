Hermes Agent Skills 精选费曼详解

说明：Skills Hub 当前可见约 17 个类别，总库约 96,883 个 skills。
本章节从每个类别中精选 3 个 最具代表性的 skill，用费曼学习法讲透。
目标：每个 skill 都让你“原来如此”，而不是“又背了一个术语”。
方法：先给一个生活化类比，再讲它到底能干什么，最后给多个真实使用场景，并附上费曼学习法实践指南。

一、AI Agents（智能体协作）

1. hermes-agent

费曼类比：就像你有一个“Hermes 自己的遥控器”，不仅能开关它，还能给它换皮肤、加新功能、安排多个 Hermes 一起干活。
用途：这是 Hermes Agent 的元技能，负责配置、主题、扩展和编排。
详细场景：

  • 你要给 Hermes 加一个自定义 Skill，就用这个 Skill 创建 SKILL.md。
  • 你要让两台机器上的 Hermes 通过 Gateway 通信，用它做 orchestrator。
  • 你要切换 Hermes 的主题配色、前缀路由、定时任务，都走这个 Skill。
    什么时候用：你要改 Hermes 的配置、加技能、调 Gateway，或者让多个 Hermes 实例协同工作。

2. computer-use

费曼类比：像给 AI 装了一双“透明手套”，能在你电脑后台点击、打字、拖拽，但不会抢你的鼠标，也不会切换桌面。
用途：后台驱动桌面 GUI，跨平台，不切换虚拟桌面，适合任何支持工具调用的模型。
详细场景：

  • 某个 SaaS 后台没有 API，只有网页表单，让 AI 模拟点击完成批量录入。
  • 你要让 AI 自动帮你下载某个网页上的文件，需要模拟点击“下载”按钮。
  • 你要让 AI 帮你安装一个桌面软件，需要一路点“下一步”。
    什么时候用：某个工具只有图形界面没有命令行，就让 AI 模拟鼠标键盘去点。

3. claude-code

费曼类比：就像你雇了一个“远程程序员 Claude”，你只需要说需求，它在终端里写代码、改 bug、提 PR。
用途：委托 Claude Code CLI 实现功能、做代码审查、提交 Pull Request。
详细场景：

  • 你要实现一个新功能，但不想自己写，让 Claude Code 在独立会话里完成。
  • 你开了一个 PR，让 Claude Code 先做一轮自动化初审。
  • 你要重构一段代码，让 Claude Code 按你的风格指南重写。
    什么时候用：项目需要改一整个模块，你不想自己写，让 Claude Code 在后台跑。

二、Productivity（办公效率）

1. google-workspace

费曼类比：像有一个“Google 办公室管家”，能帮你收发邮件、查日历、读写 Google Docs/Sheets，还能自动整理 Drive 文件。
用途：通过 gws CLI 或 Python 操作 Gmail、Calendar、Drive、Docs、Sheets。
详细场景：

  • 你要自动把日报写入 Google Sheet，用这个 Skill 直接 append 行。
  • 你要从 Gmail 提取附件并归档到 Drive 指定文件夹。
  • 你要查下周的会议安排，生成日程摘要。
    什么时候用：你要把 Hermes 的结果自动同步到 Google 生态。

2. notion

费曼类比：像有一个“Notion 私人助理”，帮你整理页面、更新数据库、同步 Markdown，还能跑 Notion Workers。
用途：通过 Notion API + ntn CLI 管理页面、数据库、Markdown、Workers。
详细场景：

  • 你要把项目进度自动同步到 Notion 数据库，每天更新状态。
  • 你要批量生成 Notion 页面，比如从 CSV 导入客户信息。
  • 你要把 Hermes 的巡检报告自动写入 Notion 知识库。
    什么时候用：你要把项目文档同步到 Notion，或自动更新数据库。

3. pdf

费曼类比：像有一个“PDF 工厂”，能合并、拆分、填表、加密，还能把扫描件变成可编辑文件。
用途：创建、合并、拆分、填写、保护 PDF 文件。
详细场景：

  • 你要把 10 个扫描件合并成一个 PDF 发给客户。
  • 你要给合同表单自动填字段，比如姓名、日期、金额。
  • 你要给 PDF 加水印、密码保护，防止泄露。
    什么时候用：你要批量处理 PDF，不想手动用 Acrobat。

三、Software Dev（软件开发）

1. github-pr-workflow

费曼类比：像有一个“PR 流水线工人”，从开分支到合并全流程帮你跑，还能帮你盯 CI。
用途：GitHub PR 生命周期：建分支、提交、开 PR、看 CI、合并。
详细场景：

  • 你要提一个标准化的 Feature PR，从创建分支到打开 PR 一条龙。
  • 你要等 CI 跑完，自动帮你合并通过的 PR。
  • 你要在 PR 描述里自动填入变更摘要和测试结果。
    什么时候用：你要提一个标准化的 Feature PR，不想手动跑 git 命令。

2. codebase-inspection

费曼类比：像请一个“代码审计员”，先数清楚项目有多少行代码、用什么语言、比例如何，给你一张“体检报告”。
用途：用 pygount 做代码库审计：LOC、语言占比、代码密度。
详细场景：

  • 你接手一个新项目，想快速了解代码规模和构成。
  • 你要做技术债评估，看看 Python/JS/TS 各占多少。
  • 你要对比两个分支的代码量变化。
    什么时候用：你接手一个新项目，想快速了解代码规模和构成。

3. dogfood

费曼类比：像有一个“测试员”，主动去你的网站里找 Bug，然后给你写一份“问题报告”。
用途：Web 应用 exploratory QA：找 bug、收集证据、生成报告。
详细场景：

  • 你刚上线一个新功能，让 Hermes 自动做一轮可用性巡检。
  • 你要在发布前做一轮回归测试，检查常见交互问题。
  • 你要监控生产环境的异常，比如 404、500、慢请求。
    什么时候用：你刚上线一个新功能，让 Hermes 自动做一轮可用性巡检。

四、Business & Finance（商业与金融）

1. airtable

费曼类比：像有一个“数据库秘书”，帮你管 Airtable 表格里的记录，比 Excel 更灵活，还能做关联查询。
用途：通过 REST API 操作 Airtable：增删改查、过滤、upsert。
详细场景：

  • 你要把 Hermes 的运行结果自动写入 Airtable 做任务管理。
  • 你要从 Airtable 读取客户列表，批量发送邮件。
  • 你要把表单提交的数据实时同步到 Airtable。
    什么时候用：你要把 Hermes 的结果自动写入 Airtable 做任务管理。

2. xlsx

费曼类比：像有一个“Excel 数据处理员”，能读写表格和 CSV，还能做批量计算和数据透视。
用途：创建、读取、编辑 Excel .xlsx 和 CSV。
详细场景：

  • 你要把数据库查询结果导出为 Excel，发给团队。
  • 你要批量填表格，比如把 100 个用户的订单信息填入模板。
  • 你要从多个 CSV 合并数据，生成汇总报表。
    什么时候用：你要把数据库查询结果导出为 Excel，或批量填表格。

3. maps

费曼类比：像有一个“地图导航员”，能查地点、算路线、转时区，还能批量处理地址。
用途：通过 OpenStreetMap/OSRM 做地理编码、POI、路线、时区。
详细场景：

  • 你要给一组长地址算配送路线，优化顺序。
  • 你要把地址转成经纬度，画在地图上。
  • 你要查某个城市的所有咖啡馆 POI。
    什么时候用：你要给一组长地址算配送路线，或把地址转成经纬度。

五、Security（安全）

1. github-auth

费曼类比：像有一个“门禁管理员”，帮你配置 GitHub 的钥匙和密码，确保只有你能进。
用途：GitHub 认证配置：HTTPS Token、SSH Key、gh CLI 登录。
详细场景：

  • 你换了机器，需要重新配置 Git 认证。
  • 你的 Token 过期了，让 Hermes 帮你生成新的 PAT。
  • 你要配置 SSH Key，让 git push 不用输密码。
    什么时候用：你换了机器，或 Token 过期，需要重新配置 Git 认证。

2. red-teaming-llms

费曼类比：像有一个“安全渗透测试员”，专门找 LLM 的弱点，看看它会不会说漏嘴、会不会被诱导。
用途：对 LLM 做红队测试：忽略/绕开拒绝话术、检测有害输出。
详细场景：

  • 你要在上线前评估模型的安全性，测试它会不会泄露系统提示。
  • 你要做对抗测试，看看模型会不会被诱导生成有害内容。
  • 你要验证模型的 guardrails 是否有效。
    什么时候用：你要在上线前评估模型的安全性，或做对抗测试。

3. secops

费曼类比：像有一个“安全运维中心”，帮你查日志、看告警、响应事件，还能自动封 IP。
用途：安全运营：日志聚合、告警、事件响应。
详细场景：

  • 服务器被扫了，你要快速查 SSH 日志、封 IP。
  • 你要监控异常登录，比如半夜来自国外的登录尝试。
  • 你要定期生成安全报告，汇总本周的告警事件。
    什么时候用：服务器被扫了，你要快速查 SSH 日志、封 IP。

六、Creative（创意产出）

1. manim-video

费曼类比：像请了一个“数学动画导演”，专门做 3Blue1Brown 风格的视频，把抽象概念变成视觉盛宴。
用途：用 Manim CE 制作数学/算法动画视频。
详细场景：

  • 你要做算法讲解视频，比如动态规划、图论。
  • 你要做数学科普，比如傅里叶变换、线性代数。
  • 你要给论文配一个精美的动画补充材料。
    什么时候用：你要做算法讲解、数学科普视频，需要精美动画。

2. baoyu-infographic

费曼类比：像有一个“信息图设计师”，能按 21 种版式 × 21 种风格出图，专为中文长图优化。
用途：生成信息图、可视化长图。
详细场景：

  • 你要把复杂数据变成一张中文长图，发小红书或公众号。
  • 你要做一份年度报告的可视化摘要。
  • 你要给产品做一个对比图，突出优势。
    什么时候用：你要把复杂数据变成一张中文长图，发小红书或公众号。

3. p5js

费曼类比：像给你一个“创意编程画板”，能画生成艺术、Shader、交互效果，还能做成网页分享。
用途：用 p5.js 做生成艺术、Shader、交互/3D 草图。
详细场景：

  • 你需要一个网页端的视觉实验，比如粒子系统、分形图。
  • 你要做一个互动艺术装置，让观众能影响画面。
  • 你要为活动做一个实时生成的背景动画。
    什么时候用：你需要一个网页端的视觉实验，比如粒子系统、分形图。

七、Research（研究）

1. arxiv

费曼类比：像有一个“论文搜救犬”，能在 arXiv 上按关键词找论文，还能按作者、分类、ID 精准定位。
用途：按关键词、作者、分类、ID 搜索 arXiv 论文。
详细场景：

  • 你要写文献综述，先让 Hermes 帮你搜最新论文。
  • 你要找某篇经典论文，用 ID 直接定位。
  • 你要监控某个领域的最新进展，定时搜索新论文。
    什么时候用：你要写文献综述，先让 Hermes 帮你搜最新论文。

2. grounded-citations

费曼类比：像有一个“引用核查员”，确保每句话都有出处，像学术界的侦探。
用途：给答案和文档加上可验证的来源引用。
详细场景：

  • 你要写学术回复或报告，要求每个论点都有依据。
  • 你要给客户写一份行业分析，需要引用权威来源。
  • 你要核实某个数据的原始出处。
    什么时候用：你要写学术回复或报告，要求每个论点都有依据。

3. research-paper-writing

费曼类比：像有一个“论文写作教练”，从选题到投稿全程陪跑，知道顶会的格式要求。
用途：ML 论文写作：NeurIPS/ICML/ICLR 从设计到提交。
详细场景：

  • 你要投顶会，需要把实验整理成符合格式的论文。
  • 你要写论文的 related work，让 Hermes 帮你梳理已有研究。
  • 你要改论文的 rebuttal，根据审稿意见调整。
    什么时候用：你要投顶会，需要把实验整理成符合格式的论文。

八、Blockchain（区块链）

1. polymarket

费曼类比：像有一个“预测市场分析师”，能查市场、价格、深度，告诉你市场对某事件的看法。
用途：查询 Polymarket：市场、价格、订单簿、历史。
详细场景：

  • 你要了解某事件的预测概率，比如“GPT-5 会不会在今年发布”。
  • 你要看某个市场的资金流向，判断市场情绪。
  • 你要追踪历史价格，做数据分析。
    什么时候用：你要了解某事件的预测概率或市场情绪。

2. etherscan

费曼类比：像有一个“区块链侦探”，能查 Ethereum 地址、交易、合约，还能看 Gas 价格。
用途：查询 Etherscan：地址余额、交易历史、Gas 价格。
详细场景：

  • 你要验证一个地址是否有异常交易。
  • 你要追踪资金流向，比如某个 ICO 的资金去了哪里。
  • 你要看当前 Gas 价格，决定什么时候发交易。
    什么时候用：你要验证一个地址是否有异常交易，或追踪资金流向。

3. wallet

费曼类比：像有一个“加密钱包管家”，帮你管私钥、签名、查余额，还能跨链管理。
用途：管理钱包：生成地址、签名消息、查询多链余额。
详细场景：

  • 你要让 Hermes 帮你签一个链上消息，证明你 owns 某个地址。
  • 你要统计自己在 Ethereum、BSC、Polygon 的资产分布。
  • 你要生成一个新的收款地址，保存到密码管理器。
    什么时候用：你要让 Hermes 帮你签一个链上消息，或统计多链资产。

九、Data Science（数据科学）

1. evaluating-llms-harness

费曼类比：像有一个“模型考官”，用标准化试卷考 LLM，你能看到它在哪些题上失分。
用途：用 lm-eval-harness 跑基准测试：MMLU、GSM8K 等。
详细场景：

  • 你要比较两个模型谁更聪明，跑一套标准 benchmark。
  • 你要评估自己微调后的模型在哪些任务上提升了。
  • 你要生成一份模型评估报告，用于论文或产品选型。
    什么时候用：你要比较两个模型谁更聪明，跑一套标准 benchmark。

2. jupyter-live-kernel

费曼类比：像有一个“notebook 助手”，帮你跑 Jupyter 代码并看结果，不用自己开浏览器。
用途：通过 hamelnb 交互式运行 Python 代码。
详细场景：

  • 你要做数据探索，不想手动开 Jupyter Lab。
  • 你要快速验证一个数据清洗逻辑，写几行代码立刻看到结果。
  • 你要画一个 Matplotlib 图表，调整参数直到满意。
    什么时候用：你要做数据探索，不想手动开 Jupyter Lab。

3. data-analyst

费曼类比：像有一个“数据分析师”，能写 SQL、画图表、做统计，还能生成报表。
用途：SQL 查询、电子表格分析、图表生成。
详细场景：

  • 你要从数据库里拉数据并生成可视化报表。
  • 你要分析用户行为数据，找出流失节点。
  • 你要做 A/B 测试的统计显著性检验。
    什么时候用：你要从数据库里拉数据并生成可视化报表。

十、Media（媒体）

1. youtube-content

费曼类比：像有一个“视频翻译员”，把 YouTube 视频变成文字稿再总结，还能写成博客。
用途：YouTube 字幕提取 + 总结成文章、线程、博客。
详细场景：

  • 你想快速吸收一个长视频的内容，让 Hermes 看字幕后给你写摘要。
  • 你要把一个技术 talk 转成博客文章，方便团队内部学习。
  • 你要把视频内容拆成多条推文，方便传播。
    什么时候用：你想快速吸收一个长视频的内容，让 Hermes 看字幕后给你写摘要。

2. gif-search

    什么时候用：你要在聊天或文档里插入一个搞笑/反应 GIF。

用途：通过 Spotify API 搜索、播放、管理播放列表和设备。

详细场景：

十二、MCP（Model Context Protocol）

1. native-mcp

费曼类比：像有一个“万能插头”，让 Hermes 能连上任何支持 MCP 的服务，比如数据库、API、文件系统。
用途：MCP 客户端：连接服务器、注册工具（stdio/HTTP）。
详细场景：

  • 你要让 Hermes 调用一个外部 MCP 服务，比如数据库查询。
  • 你要把 Hermes 接入公司内部的 API，用 MCP 包装。
  • 你要管理多个 MCP 服务器，动态注册/注销工具。
    什么时候用：你要让 Hermes 调用一个外部 MCP 服务，比如数据库或 API。

2. mcp-builder

费曼类比：像有一个“MCP 建筑师”，帮你设计、搭建、文档化 MCP 服务器，还能生成 OpenAPI 规范。
用途：设计、搭建、文档化 REST/GraphQL APIs with OpenAPI。
详细场景：

  • 你要把自己的服务包装成 MCP 供 Hermes 调用。
  • 你要为团队设计一套 MCP 工具，统一接口规范。
  • 你要生成 OpenAPI 文档，方便其他开发者接入。
    什么时候用：你要把自己的服务包装成 MCP 供 Hermes 调用。

3. mcp-for-agents

费曼类比：像有一个“MCP 设计师”，专门为 AI Agent 优化 MCP 服务器设计，让工具更容易被 AI 理解。
用途：设计/审查 MCP 服务器，让 AI Agent 更好地使用。
详细场景：

  • 你要做一个 MCP 服务，但不确定怎么设计工具接口。
  • 你要优化现有 MCP 服务的描述，让 AI 更准确地调用。
  • 你要审查 MCP 工具的安全性和权限。
    什么时候用：你要做一个 MCP 服务，但不确定怎么设计工具接口。

十三、DevOps（运维）

用途：构建、运行、调试最小 Go Web 服务，支持定时任务。
详细场景：

  • 你要监控多个 HTTP 端点，挂了就告警。
  • 你要做一个定时数据采集器，每小时跑一次。
    什么时候用：你要一个轻量级的定时健康检查或心跳服务。

2. site-monitor-bot

费曼类比：像有一个“网站哨兵”，定时 ping 你的网站，挂了就喊你，还能看历史 uptime。

  • 你要生成 uptime 报告，看看这个月挂了多久。
  • 你要监控 API 端点，延迟超过阈值就告警。
    什么时候用：你要监控多个网站， downtime 时自动发 Telegram 告警。

3. telegram-push-cron

费曼类比：像有一个“定时快递员”，每天固定时间把报告投递到 Telegram，还能读文件内容。
用途：构建定时 Telegram 推送流水线（cron + Python 脚本）。
详细场景：

  • 你要每天早上 8 点自动把美股日报推送到 Telegram 频道。
  • 你要每小时推送一次服务器状态摘要。
  • 你要在特定事件发生时推送通知，比如部署完成。
    什么时候用：你要每天早上 8 点自动把美股日报推送到 Telegram 频道。

  • 你要找视频里有没有出现特定颜色的车。
  • 你要验证某个事件是否在视频里发生。

2. vss-generate-video-report

  • 你要管理告警渠道，不同级别的事件推送到不同群。
    什么时候用：你要在检测到异常时立刻推送到 Telegram/钉钉。

十七、GitHub（代码托管）

1. github-auth

费曼类比：像有一个“门禁管理员”，帮你配置 GitHub 的钥匙和密码，确保只有你能进。
用途：GitHub 认证配置：HTTPS Token、SSH Key、gh CLI 登录。
详细场景：

  • 你换了机器，需要重新配置 Git 认证。
  • 你的 Token 过期了，让 Hermes 帮你生成新的 PAT。
  • 你要配置 SSH Key，让 git push 不用输密码。
    什么时候用：你换了机器，或 Token 过期，需要重新配置 Git 认证。

2. github-pr-workflow

费曼类比：像有一个“PR 流水线工人”，从开分支到合并全流程帮你跑，还能帮你盯 CI。
用途：GitHub PR 生命周期：建分支、提交、开 PR、看 CI、合并。
详细场景：

  • 你要提一个标准化的 Feature PR，从创建分支到打开 PR 一条龙。
  • 你要等 CI 跑完，自动帮你合并通过的 PR。
  • 你要在 PR 描述里自动填入变更摘要和测试结果。
    什么时候用：你要提一个标准化的 Feature PR，不想手动跑 git 命令。

3. github-repo-management

费曼类比：像有一个“仓库管理员”，帮你克隆、创建、Fork、发布 Release，还能清理旧版本。
用途：Clone/创建/Fork 仓库；管理 remote、release。
详细场景：

  • 你要同步多个 Repo，或批量清理旧 Release。
  • 你要 Fork 一个项目，快速开始二次开发。
  • 你要发布新版本，自动创建 tag 和 release notes。
    什么时候用：你要同步多个 Repo，或批量清理旧 Release。

费曼总结：如何真正记住这些 Skill

想象 Hermes 是一个超级瑞士军刀：

  • AI Agents = 雇佣工：让 Claude、Codex、OpenCode 替你写代码，让 computer-use 替你点鼠标。
  • Productivity = 办公室：Word、Excel、PDF、Notion、Airtable 全能操作。
  • Software Dev = 工程队：PR 流水线、代码审计、网站 QA。
  • Business & Finance = 商务秘书：表格、地图、数据库。
  • Security = 保安：GitHub 门禁、LLM 渗透测试、安全运维。
  • Creative = 艺术家：从 ASCII 画到 Manim 视频，从信息图到 ComfyUI 工作流。
  • Research = 学者：搜论文、管知识库、写论文。
  • Blockchain = 加密侦探：查预测市场、追踪链上交易、管钱包。
  • Data Science = 实验室：跑 benchmark、做数据分析、交互式 notebook。
  • Media = 媒体库：YouTube 字幕、GIF 搜索、Spotify 控制。
  • Social Media = 社交官：Twitter、多平台消息、频道分类。
  • MCP = 插头制造商：把任何服务变成 Hermes 能用的工具。
  • DevOps = 运维队：定时服务、网站监控、Telegram 推送。
  • Health = 健康管家：灯光控制、待办审计、自动完成。
  • Communication = 通信兵：邮件、SMTP、多平台消息。
  • Vision AI = 视频分析师：VSS 视频理解、报告、告警。
  • GitHub = 项目管家：认证、PR、仓库管理。

终极记忆口诀：

“Agent 帮我干活，Prod 帮我办公，Dev 帮我写代码，Biz 帮我做生意，Sec 帮我保安，Creative 帮我做设计，Research 帮我做研究，Blockchain 帮我管链，Data 帮我跑数据，Media 帮我管媒体，Social 帮我发推特，MCP 帮我接服务，Ops 帮我运维，Health 帮我养生，Comms 帮我通信，Vision 帮我分析视频，GitHub 帮我管仓库。”

（首字母 A P D B S C R B D M S M O H C V G，对应 17 个类别）

附：如何用费曼技巧自己学 Skill

  1. 挑一个 Skill：从上面选一个你从来没听说过的。
  2. 给 5 岁小孩讲一遍：用一句话类比 + 一个生活场景，不要说专业术语。
  3. 写下来：把类比和场景写成一段话，不超过 200 字。
  4. 教给别人：试着给朋友或同事讲一遍，看他们能不能听懂。
  5. 发现卡壳的地方：哪里讲不通，就去查官方文档补那块。
  6. 简化：把复杂术语换成日常词汇，直到你能脱口而出。

这就是费曼学习法的核心：如果你不能简单说清楚，说明你还没真懂。
